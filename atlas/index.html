Get your complete Google history

Google does not expose Search, Chrome, YouTube or NotebookLM history through any API — the only complete source is a Takeout export. Yours already exist in Drive (some are multi-GB); download the parts you care about and drop them here.

  1. Open takeout.google.com (or reuse the archives already sitting in your Drive).
  2. Pick the services you want: My Activity, Search, Gemini Apps, Chrome, YouTube, Gmail, Drive, NotebookLM.
  3. Prefer JSON or HTML for My Activity — both are read here.
  4. Drop the .zip straight in. The importer reads My Activity, Gemini activity, Drive file indexes and Gmail metadata from inside it.

What is read from a Takeout zip

Takeout/My Activity/*/MyActivity.{html,json}
Takeout/My Activity/Gemini*/…
Takeout/Drive/*.csv (file inventory + links)
Takeout/Gmail/*.mbox (message headers)
Takeout/Chrome/*.json (browsing history)

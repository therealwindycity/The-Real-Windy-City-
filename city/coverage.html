PAGE-LEVEL ACCESSIBILITY

Extraction and OCR status

Individual pages must be tracked as native text available, OCR generated, image review pending, or not assessed. A document should not be called searchable just because its cover memo extracts text; exhibits, maps, signatures, and tables can still be image-only.

Reported local audit result — limited scope: an audit supplied for this work found 101 page instances with no native text among 862 instances examined, including five PDFs with no native text throughout. This describes only that audited local set, not this site or all archive documents. The page-level CSV has not yet been matched to repository document IDs and is not imported here; therefore this page does not claim an overall OCR-pending count.

Once matched, each warning should identify the exact document and pages, for example: “Pages 17–23 have no usable native text. Image review/OCR status: pending.”

CLAIM LABELS

Facts, claims and analysis stay distinct

  • Original record: source file or recording, attributed to its publisher.
  • Recorded statement: what a speaker is reported to have said; caption-derived statements require source checking.
  • Verified procedural event: a motion, vote, postponement, or other event checked against an official record or recording.
  • Reported allegation / resident account: attributed report, not an established finding.
  • Editorial interpretation: analysis labeled as such, not converted into fact.
  • Unresolved question: an issue for which the available record is incomplete.
  • Correction: visible change with evidence and affected pages listed.

COUNTING RULES

Do not conflate records

  • A mirrored PDF is another stored representation, not an independent document.
  • A transcript is not official minutes; captions may contain recognition errors.
  • An agenda describes planned business, not its outcome.
  • A recommendation by a commission is not enacted law.
  • “Audio checked” means a specific passage was independently compared with the recording and logged; a video link alone is not a check.
